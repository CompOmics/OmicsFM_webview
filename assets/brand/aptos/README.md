# OmicsFM Aptos identity

The entire lowercase omics + uppercase FM wordmark uses Aptos Narrow Bold (weight 700).
Stacked versions align both lines to the same visible width. Modality colours are retained.
SVGs contain outlines only and require no installed or downloaded font in the browser.
Regenerate with `python scripts/build_aptos_brand.py --font <local-font-file>`.
The font file itself is not included in the website.
